##Brainfood

#What is Brainfood?

Brainfood is an infinity-scroll web app that presents Wikipedia content in a visually engaging format inspired by YouTube Shorts. It provides users with a seamless browsing experience, allowing them to explore random Wikipedia articles in a full-screen format with an intuitive swipe/scroll interface.

#How It Works

The app continuously fetches random Wikipedia articles, displaying key information such as the title, a short summary, and an image.

Users can scroll vertically to discover new articles in an endless stream.

Each article takes up the full screen, enhancing focus and readability.

A dark mode interface ensures a sleek and modern aesthetic, making the experience easy on the eyes.

#Who Is It For?

Curious Learners: Instantly discover new topics without needing to search manually.

Casual Browsers: Enjoy an endless stream of bite-sized knowledge in a visually appealing format.

Minimalist Readers: Engage with Wikipedia in a distraction-free and immersive environment.
